# columns-lite

三消方块街机小游戏（Columns-like）：6×13 的井里不断落下三颗一组的宝石柱，
横/竖/斜连成 3 颗以上就消除，重力让宝石下落，可连锁。贪心 AI 自动演示。

纯 Python 标准库，无第三方依赖。

## 玩法

- 井：6 列 × 13 行；每组是竖着的 3 颗宝石，颜色 6 种（●◆▲■★✚）
- 命令：`列号 [旋转]`，例如 `2` 或 `2 1`；旋转 0/1/2 循环调换三颗的上下顺序
- 落子后自动结算：找所有 3+ 连线（横/竖/斜）→ 消除 → 重力下落 → 循环，直到无可消
- 计分：每次消除 10 分/颗，连锁倍率 ×1, ×2, …
- 井满（所有列都放不下三格组）即游戏结束

## 用法

```bash
python -m columns_lite                 # 交互模式（需要终端）
python -m columns_lite --auto          # AI 自动演示（5 局，每局 200 组）
python -m columns_lite --auto --games 10 --seed 7 --pieces 300
```

## AI

1 步贪心：枚举 6 列 × 3 旋转，优先选消除数最多的落点，
平局时选堆得最低的列。没有多步搜索，不会做连锁规划。

## 已知局限（诚实版）

- AI 只是 1 步贪心，不做多步搜索，也不会主动规划连锁，人类玩家稍加思考即可超过
- 没有原版的"魔宝石"等特殊道具
- 纯文本界面，无图形/动画/音效/存档；Python 3.10+
